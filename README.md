# Galaxies Predictive · apresentação

Slides em HTML (palco fixo 16:9, sem dependências) com a identidade visual da Galaxies.

- **Ao vivo:** https://galaxies-slides.vercel.app
- **Demo:** vídeo da interface do [case_galaxies](https://github.com/igor-rodriguess/case_galaxies) no slide 14

## Navegação

| Tecla | Ação |
|---|---|
| ← → / espaço | Navegar |
| N | Notas do roteiro |
| F | Tela cheia |
| E | Editar textos (Ctrl+S baixa o HTML) |

## Deploy

```bash
npx vercel deploy . --prod
```
